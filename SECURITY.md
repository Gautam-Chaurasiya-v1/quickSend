# Security

See [docs/SECURITY.md](docs/SECURITY.md) for the implemented protocol, threat boundaries, and known limitations. QuickSend has not received an independent security audit.

Do not include credentials, identity backups, pairing/invite codes, room keys, or private message contents in public reports. Use private vulnerability reporting if the repository offers it; otherwise contact the repository owner through a private channel before posting sensitive details. No response-time commitment or bug bounty is currently offered.
